## Features

### 🌐 Public Pages & UI/UX
- **Landing Page:** Engaging hero section with interactive calls-to-action (CTAs), smooth animations/transitions, client testimonials, and highlight metrics.
- **About Us Page:** Detailed company story, core values, mission statement, and interactive team profiles.
- **Services Page:** Dynamic service cards showcasing key marketing offerings (SEO, Content Strategy, PPC, Social Media Management) with expandable details.
- **Dynamic Blog Section:** 
  - Main blog feed featuring thumbnail cards, read-time estimates, tags, and brief summaries.
  - Individual blog post pages powered by dynamic routing.
- **Contact Us Form:**
  - Client-side and server-side validation (field formatting, sanitization).
  - Automated notification email triggers upon submission.

### ⚙️ Backend & Database Integration
- **Full CRUD Functionality:** Dynamic management for blog posts and agency services via RESTful APIs.
- **Database Integration:** MongoDB with Mongoose schemas for flexible, high-speed data retrieval.

## Tech Stack

### **Frontend**
- **React.js** (Functional components, Hooks, Context API / Redux)
- **React Router DOM** (Single Page Application routing)
- **Tailwind CSS / Framer Motion** (Modern styling & smooth micro-animations)
- **Axios** (HTTP client for API requests)

### **Backend**
- **Node.js & Express.js** (RESTful API architecture)
- **Nodemailer / SendGrid** (Contact form email delivery)
- **Express Validator / Joi** (Server-side input validation)

### **Database & Hosting**
- **MongoDB Atlas** (Cloud NoSQL Database)
- **Vercel / Netlify** (Frontend Hosting)
- **Render / Railway** (Backend Hosting)

## Installation & Setup

### Prerequisites
Make sure you have the following installed on your machine:
- [Node.js](https://nodejs.org/) (v16.x or later)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- [Git](https://git-scm.com/)
- A local or cloud MongoDB instance ([MongoDB Atlas](https://www.mongodb.com/cloud/atlas))
